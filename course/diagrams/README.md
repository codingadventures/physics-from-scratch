# Diagrams

Hand-drawn diagrams as `.excalidraw.svg` files. Each one is a plain SVG (it works in a page or on GitHub) with the Excalidraw drawing embedded, so you can edit it again.

**Edit in VS Code:** install the recommended extension (`pomdtr.excalidraw-editor`, see `.vscode/extensions.json`), open the file, draw, save. The extension writes the SVG and the embedded drawing together.

**New diagram:** create an empty `name.excalidraw.svg` in this folder and open it.

**Use it in a lesson:** `![what it shows](../diagrams/name.excalidraw.svg)`. Always write alt text.

Note: `step-loop.excalidraw.svg` was generated by a script in Excalidraw's file format, not drawn in the editor. If it ever fails to open, redraw it; the first save from the extension makes it native.
